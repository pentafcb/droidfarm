## What vps-apply.sh does on the VPS (as root)

1. Preflight: all 6 stage files present, no unexpected files (fail closed —
   anything not on the allowlist aborts, and state/credential-looking names are
   refused outright), `/root/jerusalem` exists.
2. Backup: every target copied to `/root/jerusalem/.deploy-backup/<timestamp>/`
   with a MANIFEST (git hash, sha256). New files (e.g. `h264_stream.py`) are
   recorded as newly-created so rollback deletes them. Old backups pruned to 5.
3. Install: copy stage → targets (`/root/jerusalem/...`, `/usr/local/bin/...`).
4. Syntax check: `py_compile` on the 3 Python files, `bash -n` on the deployed
   watchdog. (`bash -n` on the keepalive script + entrypoint runs in the
   `deploy-all.sh` repo-side preflight, and `push-keepalive.sh` re-checks the
   keepalive before pushing it into live containers.)
   Failure → restore backups (no restart happened yet) → exit 2.
5. ffmpeg: `which ffmpeg`, else `apt-get install -y ffmpeg`. Warning-only —
   without it `/ws/h264` 501s and the dashboard falls back to MJPEG.
6. Single `systemctl restart jerusalem`; verify active + dashboard root 200.
7. Verify `/ws/h264/rbx1` → 401 expected (route live, auth enforced);
   501 = warning path (encoder unavailable, MJPEG fallback);
   anything else → rollback.
8. Check manager banner shows `H.264: True` (warning if not).
9. Observe watchdog one cron cycle (~75s): log fresh, report degraded markers.
10. Any post-install failure → **automatic rollback**: restore backups (or delete
    newly-created files), restart, re-verify.
    - exit 0: success (warnings allowed, printed as WARNING)
    - exit 1: pre-deploy failure — nothing was touched
    - exit 2: deploy failure — rolled back, old code verified running
    - exit 3: deploy failed AND rollback verification failed — MANUAL INTERVENTION

State files (`instances.json`, `roblox_accounts.json`, tokens) are never in the
stage allowlist and are never touched. No secrets are printed or transferred
(the repo tree was audited secret-free before the GitHub prep).
